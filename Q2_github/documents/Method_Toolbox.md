# Supplied FMAT3888 Method Toolbox

## Option pricing

- Expectation representation: standard Monte Carlo, antithetic sampling, importance sampling, control variates.
- SDE/path simulation: exact simulation for applicable course models, Euler-Maruyama, Milstein.
- PDE representation: explicit, implicit and Crank-Nicolson finite differences.
- American options: finite differences with an obstacle / max(exercise, continuation).
- Path-dependent / high-dimensional problems: compare Monte Carlo and finite differences according to the problem structure.

## Portfolio optimisation

- Mean, variance and covariance.
- Expected utility and risk aversion.
- Markowitz mean-variance optimisation.
- Minimum-variance portfolios.
- Efficient frontiers.
- Restricted and unrestricted optimisation.

This transcribes the toolbox supplied by the group. The original lecture notes were not supplied in this handover. Numerical solver routines implement the quadratic optimisation problem; their use is not a claim that a specific software solver was taught.
